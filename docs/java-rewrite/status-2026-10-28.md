## Defects found and fixed this session (all with regression tests)

1. HudPickHintTest hung after the first test (JavaFX implicit exit) — test setup fix.
2. **App quit by itself** when no window was visible (countdown/picker closing with the HUD hidden): `Windows` only disabled implicit exit off the FX thread. `WindowsImplicitExitTest`.
3. **No recording file ever produced**: stop-time mux spawned ffmpeg without the program path ("Cannot run program -hide_banner"). `CosmicRecorderMuxTest` (real bundled ffmpeg).
4. Stop failure left the HUD stuck on "Preparing recording" forever — stop path now always resets.
5. **Webcam recording empty**: confined FFM arena used across threads (WrongThreadException), `stop()` flag never reached the loop, capture freed under a live read, and `flip()` after absolute puts wrote 0-byte frames. Shared arena, reader owns close, one flag, `rewind()`. `WebcamRecordingLoopTest`.
6. **Webcam track half length** (camera at 15 fps fed a 30 fps stream): frames placed on the wall-clock grid (repeat/drop). Test with a 15 fps fake camera.
7. Per-frame arena allocation in webcam convert (leak) removed.
8. HUD not restored after a recording (Electron `restoreHudAfterCapture`).
9. **Recordings could not open in the editor at all** (raw cards, stop, agent `project new`): new unsaved recording session (`EditorSession.openRecording`), Save → Save As in Projects folder, rename → named save, stop → `switchToEditor`. `EditorSessionRecordingTest`.
10. New project had no clip (empty timeline, blank preview): full-length clip seeded before the store (undo-safe).
11. Editor webcam offset hard-coded to 0 in preview.
12. **Preview ignored every clip edit** (cut/split/mute/clip speed kept playing the original): `PlaybackEngine.updateClips` + audio rebuild on store change. Engine + session tests.
13. **Muted clips audible** in export and preview. `ExportAudioGraphTest`, `PlaybackFadeGainTest`.
14. **Export audio drifted from the picture** after a speed region and ignored clip speed: audio slices now follow the clip sequence (Electron offlineAudioProcessor). `ProjectExportTest`.
15. MCP: no tool worked from the dashboard ("editor did not open") — `project open/new` now works with no project open; save of an unsaved recording points to `save_as`.
16. `gravaai --mcp` never exited when the client closed stdin (orphan processes). `AgentMcpServerEofTest`.
