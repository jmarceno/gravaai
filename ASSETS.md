# Bundled media assets

Gravaai ships with wallpaper artwork, one animated wallpaper and the recording-state tray
icon. This file records where every one of those assets came from and the license it is
distributed under, so the media can be audited separately from the source code.

The application code and the original artwork in this repository are MIT licensed
(see [LICENSE.md](LICENSE.md)). The wallpaper images below are **CC0 1.0** public-domain
works: no attribution is required, and they can be redistributed, modified and bundled
with an MIT project. Provenance is listed as a courtesy and to make future audits trivial.

## Wallpapers

All images were downloaded from [StockSnap.io](https://stocksnap.io), resized to a 2560 px
long edge and re-encoded without metadata. The 16:9 previews (1280×720) and 4:3 menu
thumbnails (160×120) are centre-cropped from those files. The
StockSnap collection is published under the
[CC0 1.0 dedication](https://creativecommons.org/publicdomain/zero/1.0/); see the
[StockSnap license page](https://stocksnap.io/license).

## Animated wallpaper

`wispysky.mp4` is a 14-second forward/reverse loop made from a CC0 timelapse, cropped to
1920×1080 and re-encoded as H.264. The poster (`previews/wispysky.jpg` and
`thumbs/wispysky.jpg`) is the first frame.

## Recording icon

`app-icons/rec-button.svg` is original Gravaai artwork: a flat `#ff0e5f` dot, MIT
licensed. `app-icons/rec-button.png` is the same drawing rendered at 64×64 for the
StatusNotifierItem tray icon; `gravaai-platform/src/test/resources/icons/rec-button.png`
is the test copy.

## Logo

`branding/gravaai.png` and `app-icons/gravaai-*.png` are the Gravaai logo and application
icons. They are original Gravaai branding, MIT licensed, and remain unchanged.

## A note on file names

The wallpaper file names (`tahoe-light.jpg`, `sequoia-blue.jpg`, `wispysky.mp4`, …) are
stable project identifiers: `.gravaai` files reference them when they point at a built-in
background. The menu shows the labels from `EditorWallpapers.LABELS`.
