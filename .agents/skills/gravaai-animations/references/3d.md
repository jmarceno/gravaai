# 3D: scene3d(), models, lights and camera

`scene3d(ctx, options)` renders a 3D model into the element's 2D canvas. Everything it draws is
computed from the frame by your code — **3D animates exactly like text**: feed it `frame`-derived
rotation/position/scale and it is a pure, deterministic animation.

It is the engine behind `gravaai/model-3d` (a turntable with a spring entrance); call `scene3d`
directly when you want camera moves, multiple objects or custom lighting.

```js
scene3d(ctx, {
  model: "product",        // a model asset name, or a built-in shape (below) — required
  x: 0, y: 0,              // viewport position inside the element box (default: 0,0)
  width: 500, height: 500, // viewport size (default: the whole box)
  rotation: [10, 45, 0],   // Euler [x, y, z] in degrees
  position: [0, 0, 0],     // world offset [x, y, z]
  scale: 1,                // 0–100, default 1 (model is normalised to a unit sphere)
  cameraDistance: 3,       // 0.2–1000; camera sits on +Z looking at the origin
  fov: 35,                 // 5–150 degrees, default 35
  ambient: 0.35,           // 0–1
  specular: 0.3,           // 0–1 (Blinn highlight strength)
  tint: "#ffffff",         // multiplies the model's own colours
  light: { color: "#ffffff", direction: [-0.5, 0.8, 0.6] },  // one directional light (normalised)
});
```

## Models

- **Assets:** `.glb` / `.gltf` with **embedded buffers** (max 24 MB, like any asset), referenced by
  asset name. `position`/`scale` are relative to the model's own size — every model is centred and
  normalised to a unit sphere first, so the same camera framing works for any model.
- **Built-in procedural shapes** (no asset needed): `gravaai:cube`, `gravaai:sphere`,
  `gravaai:torus`, `gravaai:torus-knot`. Great for placeholders and abstract motion graphics.
- Rendering uses OpenGL 3.3 with MSAA and falls back to a software renderer when there is no GL
  context (headless exports, VMs) — nothing to configure, but frame-rate-heavy scenes may cost
  more on the fallback.

## Coordinate system

World units are "model radii": a default model spans about 2 units. The camera is on +Z at
`cameraDistance` (default 3) looking at the origin. `position` moves the model in world units;
`rotation` is applied as a single XYZ Euler in degrees.

## Lighting

One directional key light plus ambient, with a Blinn-Phong specular highlight (`specular` 0 kills
it). `tint` multiplies the albedo — tint to brand colours, or animate tint for a glow sweep. For a
"light sweep", rotate `light.direction` slowly over time instead of the model.

## Draw order

`scene3d` **flushes the 2D command batch first**: whatever you drew before the call is behind the
model, whatever you draw after is in front. Compose backgrounds, models and 2D labels freely:

```js
ctx.fillStyle = shader(BACKDROP, { uSize: [width, height], uTime: seconds });
ctx.fillRect(0, 0, width, height);
scene3d(ctx, { model: "gravaai:torus-knot", rotation: [15, seconds * 40, 0], scale: pop });
ctx.font = "bold 42px sans-serif";          // in front of the model
ctx.fillStyle = "#fff"; ctx.textAlign = "center";
ctx.fillText("Gravaai 2.0", width / 2, height * 0.85);
```

## Patterns

**Turntable** (what `gravaai/model-3d` does): `rotation: [tilt, seconds * spinSpeed, 0]`.

**Spring entrance:** multiply `scale` by a spring —
`scale: props.scale * spring({frame, fps, config:{damping: 12}})`. Note the spring overshoots,
which reads as a lively pop; clamp with `Math.max(0, …)` so it never inverts.

**Camera dolly:** animate `cameraDistance` —
`cameraDistance: interpolate(frame, [0, durationInFrames], [6, 3.2], {extrapolateRight:"clamp", easing: Easing.inOut(Easing.cubic)})`.

**Multiple objects:** two `scene3d` calls with different `position`/`width`/`height`; the second
draws in front (within one element, split the box yourself via `x/y/width/height`).

**Fade in/out:** set `ctx.globalAlpha` before the call (as `gravaai/model-3d` does for its exit) —
it applies to the rendered model.

**Full worked example** — a product intro: dolly-in camera, light sweep, 2D tagline:

```js
export const fps = 30;
export const durationInFrames = 120;
export const defaultProps = { model: "gravaai:torus-knot", spin: 35 };
export const propsSchema = { model: "string", spin: { type: "number", min: -360, max: 360 } };
export const description = "3D product intro: dolly-in, light sweep, tagline";

export function render(ctx, { frame, fps, durationInFrames, width, height, props }) {
  const seconds = frame / fps;
  const pop = Math.max(0, spring({ frame, fps, config: { damping: 13 } }));
  const out = interpolate(frame, [durationInFrames - 15, durationInFrames], [1, 0],
                          { extrapolateLeft: "clamp" });
  ctx.globalAlpha = out;
  scene3d(ctx, {
    model: props.model,
    rotation: [12, seconds * props.spin, 0],
    scale: pop,
    cameraDistance: interpolate(frame, [0, durationInFrames], [6.5, 3.2],
      { extrapolateLeft: "clamp", extrapolateRight: "clamp", easing: Easing.inOut(Easing.cubic) }),
    fov: 40,
    light: { color: "#ffffff",
             direction: [Math.cos(seconds * 0.8) * -0.7, 0.8, Math.sin(seconds * 0.8) * 0.4] },
    ambient: 0.3, specular: 0.45,
  });
  const tagline = interpolate(frame, [30, 45], [0, 1],
    { extrapolateLeft: "clamp", extrapolateRight: "clamp", easing: Easing.out(Easing.cubic) });
  ctx.globalAlpha = out * tagline;
  ctx.font = "bold 54px sans-serif"; ctx.textAlign = "center";
  ctx.fillStyle = "#ffffff";
  ctx.fillText("Introducing Gravaai 2.0", width / 2, height * 0.88);
}
```

## Choosing 3D vs 2D

Reach for `scene3d` when depth, perspective or lighting carries the idea (product reveals, logo
turntables, orbiting abstract shapes). For flat motion graphics (slides, wipes, counters), 2D is
cheaper and easier to art-direct. Mixing is normal: a scene-space `gravaai/callout` pointing at a
3D element works exactly like pointing at screen content.
