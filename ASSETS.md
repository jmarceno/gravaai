# Bundled media assets

Gravaai ships with wallpaper artwork, one animated wallpaper, the recording-state tray icon
and the cursor sprites. This file records where every one of those assets came from and the
license it is distributed under, so the media can be audited separately from the source code.

The application code and the original artwork in this repository are MIT licensed
(see [LICENSE.md](LICENSE.md)). The wallpaper images below are **CC0 1.0** public-domain
works: no attribution is required, and they can be redistributed, modified and bundled
with an MIT project. Provenance is listed as a courtesy and to make future audits trivial.

## Cursor sprites

The cursor sprites under `java/gravaai-media/src/main/resources/dev/gravaai/media/cursors/`
are selected outline cursors from [Kenney's Cursor Pack](https://kenney.nl/assets/cursor-pack),
which is released under **CC0 1.0**. The I-beam is composed from the pack's line shapes. The
style names (`macos`, `tahoe`, `windows11`, `golden-gate`, `figma`) are picker labels; every
sprite comes from the same CC0 pack. The pack's license is reproduced in
`java/gravaai-media/src/main/resources/dev/gravaai/media/cursors/LICENSE.txt`.

## Inference runtime

ONNX Runtime itself and its GPU plugin ship as native payload under
`java/native/build/onnxruntime/lib/` (staged by `java/native/build-onnxruntime.sh`, pinned by
SHA-256):

| File | Size | License | Source |
| --- | --- | --- | --- |
| `libonnxruntime.so.1.31.1` | 29,345,384 B | MIT | [onnxruntime v1.31.1, linux-x64](https://github.com/microsoft/onnxruntime/releases/tag/v1.31.1) |
| `libonnxruntime_providers_webgpu.so` | 16,613,128 B | MIT | [onnxruntime-ep-webgpu 0.5.0](https://pypi.org/project/onnxruntime-ep-webgpu/0.5.0/) `manylinux_2_28_x86_64` wheel |

The WebGPU plugin is the vendor-neutral GPU execution provider for the optional deep-zoom
upscaler: on Linux it runs through Dawn on **Vulkan**, so one library covers AMD (RADV/AMDVLK),
Intel (ANV) and NVIDIA. It is registered into the stock runtime at startup and is not a second
ONNX Runtime. The system Vulkan loader (`libvulkan.so.1`) is a runtime requirement and is **not**
bundled — it must match the host driver. Without it (or without a GPU) the app stays on the CPU
provider. The plugin is MIT licensed; its licence text ships with the wheel it is extracted from,
and the staged `.so` is the only file distributed here.
